# 原创边界与反面清单

动笔前粗读一次，改稿第五遍再逐项核。

## 硬边界

只借五类可复述的手法：双世界并置、力量与代价挂钩、平凡视角的自嘲声音、喜剧与悲剧的落差节奏、青春情绪的物件化。

禁止出现：

- 任何既有作品的专有名词、人物名、组织名、地名、能力名、等级名。
- 标志性台词与近似改写，尤其是「拿某样东西来换吗」式的交易句、角色口号、卷末名句。
- 可辨认的情节节点与人物组合：学院制特招、指定血统评级、特定雨夜或列车或水坝或都市地标的关键场面、特定角色的牺牲与重逢。
- 沿用既有世界观架构只换名字。

自检方法：把作品里所有专名换成占位符之后，如果仍能一眼认出是哪本书的哪一卷，说明改得不够，重做世界规则与关键事件。

用户明确要求同人创作时，按用户给的边界处理，仍不复制原句段落，并说明版权与发布风险由用户自行判断。

## 检查用清单

明确专名，命中即判失败，与 `scripts/check_novel.py` 的 `FORBIDDEN_NAMES` 一致：

- 卡塞尔、路明非、楚子航、恺撒、诺诺、绘梨衣、昂热、芬格尔、源氏重工、尼伯龙根、奥丁、白王、黑王、尼德霍格。

可能属于通用奇幻词汇，只作提醒，由作者判断是否在原创世界内自洽，与脚本的 `REVIEW_TERMS` 一致：

- 言灵、龙王、血统、S级、屠龙、混血种、龙族、交换吗。

改动清单时同一轮修改脚本，不让脚本偷偷多出一套规则。

## 常见 AI 味症状与修复

| 症状 | 表现 | 修复 |
| --- | --- | --- |
| 每页都燃 | 一章三次掀桌，句句可截图 | 一章留一到两次，其余写生活运转 |
| 中二宣言 | 人物对着空气讲使命与宿命 | 改成对具体的人说一句具体的话，或直接做 |
| 设定说明书 | 开篇三段讲等级与组织沿革 | 等人物第一次撞上规则再讲，一场最多两三个专名 |
| 金句体 | 每段末尾一个短判断 | 普通地方用普通句子结束 |
| 情绪翻译 | 写完动作再写「他其实很害怕」 | 删解释，留动作 |
| 意象拼盘 | 雨、血、月亮、潮水、火焰、废墟轮番上 | 只留跟当前场景同一套感受的一两个 |
| 梗表演 | 吐槽密度高到盖过事情 | 一段最多一处，参照物合人物年代 |
| 情感对象工具化 | 只负责漂亮、被救、牺牲、给线索 | 给她一件眼下要办的事和一次拒绝 |
| 代价蒸发 | 能力用了几次，什么都没少 | 台账登记，后文兑现 |
| 假具体 | 精确时间、天气、摆设一大串却不改变行动 | 删到视角人物会注意的两三样 |
| 钩子口号 | 「他还不知道，真正的危险才刚开始」 | 换成一个具体问题 |
| 结尾升华 | 末段点题，回到世界与时代 | 停在一个动作或关系的新位置 |
| 人物同声 | 遮住名字分不出谁在说 | 给每个人一个不肯回答的问题 |
| 万能救场 | 临时新规则、失忆、双胞胎、遗嘱 | 关键转折改从此前行动与规则里长出来 |
| 孤独靠喊 | 直接写「他很孤独」「没有人懂他」 | 写一个没送出去的东西和一个空掉的座位 |
| 翻案句成瘾 | 「不是……而是……」当洞察 | 拆回两句事实陈述 |
| 全局黑话 | 底层逻辑、闭环、赋能混进叙述 | 改成人、动作、时间、后果 |

## 一段对照

反例：

> 雨夜，他站在天台上，终于明白自己不是普通人，而是被命运选中的人。孤独像潮水般涌来，更大的危险，才刚刚开始。

修复方向：

> 天台门没锁。他把书包放在水塔旁边，掏出手机看了一眼，屏幕上是三条没发出去的消息。
>
> 楼下有人在喊他名字，喊了两声就停了。
>
> 他坐下来，把书包往里推了推，免得淋湿。

修复后靠物件、动作、被打断的期待和不解释的情绪，没有抽象名词、翻案句和预告。
