# 文学资料索引

这批资料整合自工作区 `skills/` 下四个已打磨的 skill，现在作为 `inkos-long-writing` 的静态参考资料随包发布。**用途只有一个：给长篇小说借技法，写出有文学质感的作品**。不是把网文改行成报告、论文或教材讲义，也不是给作品贴类型标签。

`dickens-bildungsroman.md` 是本目录的总纲：把《大卫·科波菲尔》一类成长小说的可迁移技法、可对照的作品坐标，以及和商业套路的差别讲清楚。先读它，再按问题查下面四组资料。

## 使用原则

1. **只借方法，不搬文本**：资料用于判断类型、拆技法、找反面案例，不复制任何作品的措辞、人名、场景顺序或标志性组合。
2. **类型契约是默认，不是上限**：知道惯例是为了写得更准，不是为了拿它否定人物、细节与主题的深度。
3. **不编造事实**：流派年份、奖项、销量、教材篇目、子类型沿革，资料里写了才用；资料没写或标了异说的，照实说「通行说法」或「待核对」，不替它补数字。
4. **别把风格词当流派**：「诗化」「冷峻」「白描」是风格，「浪漫主义」「现实主义」是思潮，「乡土」「都市」多是题材。
5. **网络类型与产业数据更新快**：涉及平台、榜单、子类型时注明资料日期；不把产业口径当成美学标准。
6. **不追求商业性**：这些资料服务于作品质量，不服务于爽点密度、追读曲线、卖点与封面。用户明确要求商业节拍时再单独启用，默认不启用。

## 与写作链路的关系

- `inkos-long-writing` 负责把技法落进场景、人物与结构；
- `inkos-short-writing` 负责单篇成稿，同样不做销售包装；
- `inkos-story-review` 按作品自身契约审，含人物、生活质地、语言与主题的维度；
- `inkos-story-deslop` 恢复具体的人与可观察的世界；
- 四个 skill 共用 `references/outline-voice.md`，大纲一律说人话。

草稿区原包保持不变，历史版本与完整脚本仍在那里；本目录是整合后的随包副本。
