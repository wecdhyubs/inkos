# 赏析与创作：按类型可复用的工序

`taxonomy.md` 给坐标，`movements.md` 与 `genre-fiction.md` 给资料，这份文件给**动作**：拿到文本问什么、写成什么格式、动笔按什么顺序。

## 1. 通用赏析八问（任何类型都先过一遍）

1. **契约**：读者被许诺了什么？作品自己在开头几页有没有把这个许诺摆出来（一个谜、一次失踪、一个异常、一段关系）？
2. **世界**：这个世界的规则边界在哪？哪些事在这里算「不可能」？
3. **解释权**：叙述者解释多少、何时解释、对谁解释？人物是争论真伪还是争论后果？
4. **信息释放**：读者与人物各自在什么时候知道什么？哪里被有意压住，压住是否产生收益？
5. **结构**：关键节点在哪几页？结尾回应的是开头那个许诺，还是另起了一个？
6. **人物功能**：每个人物替契约做什么（给线索、制造阻力、代表社会、承担代价）？
7. **语言**：句长、语气、感官密度与类型是否相称？有没有用抒情或术语给空段落抬价？
8. **历史与生产**：写于何时、发在哪里、给谁读、当时这个类型的惯例是什么？偏离惯例是有意还是失手？

## 2. 按类型的三问清单

| 类型 | 必问三问 | 常见证据落点 |
| --- | --- | --- |
| 科幻 | novum 是什么／推演到第几层／有没有靠设定说明跳过推演 | 制度、职业、物价、家庭作息的变化；技术解释出现的时机 |
| 奇幻 | 规则何时公布／是否一贯／代价是否真付了 | 规则的首次陈述、破例处、旅程结构 |
| 推理 | 线索是否都提前给过／解答只用已知信息吗／干扰是否公平 | 线索表、时间表、「向读者挑战」的位置 |
| 哥特恐怖 | 恐惧来自哪里／哪页确认超自然／走的是犹疑、理性化还是接受 | 空间描写、退路被关、叙述者回避处 |
| 武侠仙侠 | 「侠」被定义成什么／能力边界在哪／成长付了什么代价 | 师承与规矩、决斗场面、结局的价值裁决 |
| 言情 | 抽掉爱情线故事塌不塌／阻力是否长在人物身上／结局是否挣得出来 | 靠近与退缩的节拍、黑时刻、结尾的承诺证据 |
| 历史 | 不动清单与可动清单各是什么／时代限制是否真限制了人物 | 器物、制度、称谓、史实的接缝 |
| 成长 | 出走的触发是什么／每次改变付了什么代价／整合还是拒绝 | 失落事件、导师与反例、结尾的社会位置 |
| 乡土市井 | 风物是背景还是结构／方言谁在说／没有冲突靠什么推进 | 节气、饭桌、物象的反复、目光与走动 |
| 网络类型 | 兑现的最小单位是什么／规则是否被遵守／读者反馈留下什么痕迹 | 章节钩子、数值变化、任务发布处 |
| 流派／思潮 | 反对什么／形式指纹是什么／作家认不认这个标签 | 碎片化、零度叙述、元叙事、白描、原生态细节 |

## 3. 输出模板（四种常用交付）

### 3.1 类型定位卡

```
主类型（读者契约）：______；一句话契约：______
次要类型／叠加层：______
第 1 轴体式：______  第 2 轴题材：______
第 4 轴流派／思潮：______  第 5 轴叙事模式：______
生产与接受：______（连载／平台／读者群，若适用）
三处证据：①______ ②______ ③______
相邻边界：与______的分界在于______
保留意见：______（归类有争议／跨类型／节选或版本差异）
```

### 3.2 单篇赏析

按「契约 → 惯例 → 兑现／偏离（带证据）→ 历史与生产条件 → 相邻类型对照 → 判断与余地」六段写；每段至少挂一处具体句子或场景。禁止「反映了社会现实」「想象力丰富」独立成句。

### 3.3 类型比较

先写共同契约，再写分岔点，最后各给一段文本证据；不写成两篇独立的内容简介。推荐比较轴：世界规则、解释额度、人物反应、结局兑现、生产条件。

### 3.4 创作提案

只给「契约一句话 + 五条必付惯例 + 一处反套路 + 节拍 + 语气」五项，不预先写完整情节，不附设定表。

## 4. 类型节拍表（创作第 5 步用）

节拍是契约的时间展开，不是公式；反套路时只动其中一节。

| 类型 | 节拍 | 最容易写坏的一节 |
| --- | --- | --- |
| 本格推理 | 异常／案发 → 线索与干扰 → 排除与误答 → 挑战读者 → 解答与复核 | 关键线索只在解答章首次出现 |
| 硬汉／社会派 | 委托 → 走访 → 牵出制度 → 侦探受损 → 局部解决、整体不解决 | 把社会成因写成一段演讲 |
| 言情 | 相遇 → 靠近 → 阻力显形 → 黑时刻 → 修复 → HEA／HFN | 黑时刻由误会而非人物信念造成 |
| 成长 | 失落 → 出走 → 试炼与导师 → 与社会冲突 → 整合或拒绝 | 用一次顿悟代替多次修正 |
| 科幻 | novum 出现 → 日常被改写 → 推演升级 → 认知反转 → 新常态 | 停在奇观，不推到制度与生活 |
| 奇幻 | 召唤／失衡 → 进入第二世界 → 规则学习 → 代价支付 → 归来与秩序重建 | 规则为剧情让路 |
| 恐怖／哥特 | 不对劲 → 退路收窄 → 延宕 → 确认或继续犹疑 → 余波 | 过早给出机制说明 |
| 武侠／仙侠 | 变故 → 入江湖／入门 → 学艺与结仇 → 价值抉择 → 裁决 | 只堆招式与等级，不写代价 |
| 网络连载 | 困境 → 金手指／任务 → 数值成长 → 关卡与反转 → 兑现 → 新钩子 | 系统替人物做价值抉择 |

## 5. 同一前提，七种写法

前提：**腊月廿三，县供销社后院多了一道门，门牌是 7 号，可那条巷子从来只有 6 个门牌。**

这一组对照用来说明：决定写法的不是「门」这个道具，而是类型契约与解释额度。

| 类型 | 样张（各一句） | 解释额度 | 读者要什么 |
| --- | --- | --- | --- |
| 奇幻 | 门后的人查验通行证，说第七道门三十年只开一次，进去的人得留下一样再也拿不回来的东西。 | 规则明确、代价明确 | 自洽世界与任务的完成 |
| 科幻 | 县里先给巷子重新编号，再派两个人拿卷尺量了三天，第五天起粮站的排队顺序改了新的办法。 | 可推演，重心在制度后果 | 一个 novum 推到底 |
| 哥特／恐怖 | 腊月里那扇门一直往外渗冷气，守夜的人第二早少了一只鞋，谁也没敢说门是什么时候开的。 | 延后、最好不解决 | 恐惧或犹疑被悬置 |
| 魔幻现实主义 | 主任让人把 7 号牌钉上去，会计说这个月门牌费得单独记一笔。 | 完全不解释，人物只处理后果 | 被否认的真实借异常显形（深判定与写法转 `magic-realism`） |
| 本格推理 | 门牌是新的，钉子却是旧的；巷口修鞋的记得六号人家搬走那天，有人借走过一把锤子。 | 结尾给可复核解答 | 公平线索与解答 |
| 言情 | 她在那道门前等了三个腊月，今年门开了，出来的人还拿着当年没还的那半张车票。 | 门是关系装置，不解释来源 | 阻力、黑时刻与 HEA／HFN |
| 网络类型 | 【副本已开启：第七号门】任务发布，奖励：经验值＋200，倒计时 23:59。 | 规则数值化、前置 | 持续兑现与下一次钩子 |

再换到第 4 轴看同一前提：若写成**新写实**，那道门根本不会被当作奇事，只写房管所来登记、居委会为门牌吵一架、主人公排队办手续到天黑，「异常」被消解成日常琐事；这正是「流派改变了什么算事件」。若写成**元小说**，叙述者会出面讨论「这一章本来不该有门」。

## 6. 创作工序细化

1. **写契约声明**（内部，不交读者）：「本书属于______，读者读完应当得到______；若没有，就是我毁约。」
2. **列惯例清单**：从 `genre-fiction.md` 对应条目抄 5 条，逐条写一句「我打算在第几节怎么给」。跨类型时给主契约打星号。
3. **选一处反套路**：写清「破哪条、为什么、代价由谁承担」。例如推理把解答前置，代价是全书改成「读者看着人物一步步撞上已知结局」。
4. **做信息释放表**：三列——「事实 / 读者何时知道 / 人物何时知道」。推理与恐怖最依赖这张表；言情与成长则看重「人物比读者早知道什么」。
5. **定语气与解释额度**：硬科幻精确、新写实零度、哥特压抑、武侠说书感、网文短促。把「不解释」「最后解释」「边发生边解释」三者选一，写进契约。
6. **按节拍写，不按设定写**：每一节都要推进契约（多一条线索、多一次靠近、多一层推演），设定只在人物需要它做决定时出现。
7. **体检**：过 `SKILL.md` 的八项体检 + 本文件第 8 节自检；长稿跑 `python scripts/find_genre.py <稿件路径>` 看类型线索是否与契约一致，脚本只提示线索，不替人归类。

## 7. 常见误读（速查 18 条）

1. 有鬼、有变形、有奇事就称「魔幻现实主义」。
2. 有飞船、有机器人就叫「硬科幻」；把「硬／软」当优劣。
3. 把奇幻第二世界的规则，当成魔幻现实主义的「设定」，或反过来要求魔幻现实主义给出规则。
4. 用 Todorov 的「犹疑」去要求所有超自然文本，忽略 uncanny 与 marvelous 两端。
5. 把「诗化」「散文化」「冷峻」写成文学流派。
6. 把题材（乡土、历史、职场）写成类型契约，或把流派（新历史）写成历史小说。
7. 把「网络连载／男频女频」写成美学类型或文学缺陷。
8. 把成长小说等同于「主角是少年」；认为成长必须成功。
9. 把悲剧爱情标成言情／罗曼史，或用 RWA 的 HEA 标准去否定中文言情传统。
10. 把「有案件」当推理，忽略线索公平与解答可复核。
11. 把「变格派」「设定系」当作无争议的固定分类。
12. 把哥特元素（阁楼、疯女人、雷夜）当成整部作品的归类依据。
13. 把武侠等同于奇幻，或把仙侠／玄幻的升级机制倒套到民国旧派武侠。
14. 把《变形记》归为魔幻现实主义：前者是现代主义的荒诞，用极度写实的细节写不可能。
15. 把《促织》归为魔幻现实主义：它是文言志怪与浪漫主义幻想，有明确因果、有「异史氏曰」出面评判。
16. 把「荷花淀派」「山药蛋派」当成有宣言有组织的文学社团。
17. 替作家断言流派归属，忽略作家本人的否认与跨期变化（如余华早期先锋与后期写实）。
18. 引用平台榜单、奖项年份、读者规模、市场数字却不写资料日期，或编造精确数字。

## 8. 质量自检（交稿前逐项打勾）

- [ ] 五轴都落了点，且没有把某一轴的取值当成另一轴。
- [ ] 契约写成了一句可证伪的话，不是「好看」「有深度」。
- [ ] 赏析结论至少挂三处文本证据；创作提案没有提前写完整情节。
- [ ] 与至少一个相邻类型做过对照，并写出分界判据。
- [ ] 跨类型作品标了主／副契约；有争议的归类写了保留意见。
- [ ] 精确年份、奖项、平台数据都标了来源级别或「通行说法／据某年资料」。
- [ ] 没有把风格词、题材词、媒介词升级成流派结论。
- [ ] 涉及在世作家只用了可复述的手法特征，没有仿写原句或复用专有设定。
- [ ] 成品用简体中文；外文术语首次出现附原文。

## 9. 术语白话表

| 术语 | 白话 |
| --- | --- |
| 读者契约（reader contract） | 类型向读者许诺的东西，标签一挂就生效 |
| 惯例（convention） | 读者默认会有的期待，不是必须照抄的套路 |
| novum | 科幻里那个「新东西」，故事从它推出去 |
| 认知疏离（cognitive estrangement） | 用可理解的新设定把熟悉世界变陌生，好重新看见它 |
| 第二世界（Secondary World） | 奇幻里自成一体的架空世界 |
| fantastic / uncanny / marvelous | 一直犹疑不决／最后有理性解释／一开始就接受超自然 |
| antinomy | 两套冲突却各自自洽的现实编码同时并存（魔幻现实主义） |
| HEA / HFN | 结局给出长久承诺／此刻在一起且向好 |
| 元小说（metafiction） | 小说公开谈论自己是被写出来的 |
| 叙事模式（mode） | 讲述机制，如限知视角、意识流、框架叙事 |
| 生产与接受轴 | 在哪儿发、怎么连载、谁在读、反馈如何进入文本 |
| 金手指 | 网络小说里主角的外挂，本质是一组可数值化的规则 |
