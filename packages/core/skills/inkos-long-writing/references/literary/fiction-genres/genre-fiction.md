# 类型小说逐类（第 3 轴 · 读者契约）

每条按同一套字段写：**契约 → 机制 → 子类型与年表 → 代表作 → 赏析抓手 → 创作要点 → 易错与边界**。「契约」是判断该用什么标准评价作品的依据：先问它许诺了什么，再问兑现得如何。

年份与子类型多来自 B／C 级资料，精确数字回 `taxonomy.md` §6、§7 复核；网络类标签更新快，引用一律带日期。

---

## §1 科幻 Science Fiction

- **契约**：给出一个新事物（novum），并把它对人物、制度与日常生活的后果**推演到底**；读者买的是「如果这个成立，世界会怎样」。
- **机制**：Suvin 的「认知疏离 + 认知逻辑验证的 novum」。关键不在道具像不像科学，而在文本是否把新事物当作原则上可解释、可推演的东西来经营（`taxonomy.md` §3.3）。
- **子类型与年表**：1818《弗兰肯斯坦》常被称第一部（有争议）→ 凡尔纳的工程细节／威尔斯的社会推演 → 1926 Gernsback 办《Amazing Stories》推广 `scientifiction` → 1930s–50s Campbell 主编《Astounding》的「黄金时代」（阿西莫夫、海因莱因、克拉克，解题式英雄）→ 1960s–70s「新浪潮」（`New Worlds`，转向心理学、人类学、文体实验，勒古恩、迪克）→ 1980s 赛博朋克（《神经漫游者》，高科技／低生活、公司权力、人机边界）→ 当代全球化（刘慈欣《三体》等）。常见分支：硬科幻（严守已知物理，克拉克、哈尔·克莱门特、《火星救援》、金·斯坦利·罗宾逊）、软科幻（社科与心理）、太空歌剧（《基地》《沙丘》）、反乌托邦、架空历史、时间旅行、末日／后末日、气候小说。
- **代表作**：《弗兰肯斯坦》《时间机器》《世界大战》《基地》《沙丘》《黑暗的左手》《仿生人会梦见电子羊吗？》《神经漫游者》《三体》《索拉里斯》。
- **赏析抓手**：① novum 用一句话说得清吗；② 推演停在哪一层（技术／经济／家庭／语言／伦理）；③ 有没有用大段「设定说明」跳过推演；④ 科学细节与人物处境是否是同一件事的两面。
- **创作要点**：只立一个 novum，先写它怎样改变普通人一天的安排，再写奇观；规则一经写出就别为情节破例；解释放在人物需要它做决定时。
- **易错**：硬／软是取向不是等级；有飞船不等于科幻；把科幻当「预言是否应验」；用「未来世界」四个字代替社会结构。

## §2 奇幻 Fantasy

- **契约**：一个自洽、有规则的第二世界（或魔法侵入现实的世界），人物在其中完成一件有代价的事；读者预期规则会被交代、会被遵守。
- **机制**：Tolkien「可让心智进入的第二世界」；魔法通常有来源、限制与代价，人物**承认魔法特殊**（与魔幻现实主义相反）。LibreTexts 按离日常世界多远分级：high fantasy（完全架空）／low fantasy（portal 人物进入异界、intrusion 魔法侵入现实）。
- **子类型与年表**：20 世纪中叶 Tolkien《魔戒》、C.S. 路易斯《纳尼亚》、勒古恩《地海》确立高奇幻范式 → 后期《冰与火之歌》把政治与生态引入 → 《哈利·波特》代表 intrusion／隐藏社会式低奇幻 → 当代多元化（以非欧洲神话为基底的架空世界）。中文脉络里还珠楼主《蜀山剑侠传》开「奇幻仙侠」格局，后接网络玄幻（§5、§10）。
- **代表作**：《魔戒》《纳尼亚传奇》《地海传奇》《冰与火之歌》《哈利·波特》（隐藏社会式低奇幻）、《蜀山剑侠传》。
- **赏析抓手**：规则何时向读者公布、是否前后一贯；代价是否真的被支付；旅程结构与善恶框架是沿用还是被改写；世界细节是否服务于人物处境。
- **创作要点**：先把规则与代价想完整，只写人物当下需要的那部分；地图、年表、语言是工具不是正文；给魔法设一个「不能解决的事」，否则情节没有张力。
- **易错**：与魔幻现实主义混淆（本世界／不解释／不惊讶 vs 第二世界／有规则／会惊讶）；与科幻混淆（魔法 vs 可推演的 novum）；把「有龙」当奇幻的充分条件。

## §3 推理 / 侦探 Detective Fiction

- **契约**：**公平**——读者与侦探拿到同一批线索；结尾给出可复核的解答。这是所有子类型里契约最硬的一类。
- **机制**：谜团（常是不可能犯罪）→ 线索与干扰 → 排除与解答；核心乐趣是读者与作者的智力博弈。
- **子类型与年表**（据推理专栏与流派词条，精确年份属 B 级资料）：1841 爱伦·坡《莫格街凶杀案》确立侦探＋助手、密室、安乐椅侦探、暗号等原型 → 柯南·道尔福尔摩斯 → 1920 阿加莎《斯泰尔斯庄园奇案》开启长篇「黄金时代」 → 1928 范达因《侦探小说二十守则》与诺克斯《十诫》把「公平」写成明文 → 黄金时代三巨头（阿加莎、艾勒里·奎因、约翰·迪克森·卡尔；奎因有「向读者挑战」） → 1930s 美国硬汉派（哈米特《马耳他黑鹰》、钱德勒《漫长的告别》，侦探不全能、社会腐败） → 1957 松本清张《点与线》开启日本社会派（重「为什么杀人」与制度成因，弱化神探） → 1981 岛田庄司《占星术杀人魔法》、1987 绫辻行人《十角馆事件》开启新本格（现代条件下重写解谜） → 后续日常推理（米泽穗信《冰菓》）、设定系（西泽保彦《死了七次的男人》、今村昌弘《尸人庄谜案》）。旁支：法庭推理（卡尔《犹大之窗》）、历史推理（铁伊《时间的女儿》）、叙述性诡计、密室与不在场证明。
- **代表作**：上列各条，另可举《东方快车谋杀案》《三口棺材》《无人生还》《白夜行》《模仿犯》。
- **赏析抓手**：做一张线索表——每条线索出现的位置、当时被解释成什么、解答时如何 reuse；检查解答是否只用了已给出的信息；看诡计与社会批判是互相支撑还是两张皮。
- **创作要点**：先定诡计、时间线与线索表，再写人物与场景；关键线索要藏在「看起来是别的东西」里，不能藏在叙述者没写的空白里；写完请人只凭前 90% 猜一次。
- **易错**：把「有案件」当推理；关键线索最后一章才出现却标榜公平；叙述性诡计隐瞒叙述层信息是否算不公平，各家标准不同，需声明；设定系必须**前置**架空规则，评论界对其公平性仍有争议；「变格派」是否算独立流派有分歧（有论者认为缺少合理解答就不算推理）。

## §4 哥特 / 恐怖 Gothic & Horror

- **契约**：恐惧被兑现——或以「无法判断真假」的犹疑被有意悬置。读者接受被惊吓，但不接受悬置之后草草给个设定说明。
- **机制**：信息延宕、封闭空间、被压抑的过去、身体与家族秘密；Todorov 三分在这里最好用：最后理性化 = uncanny；始终不决 = fantastic；一开始接受超自然 = marvelous（`taxonomy.md` §3.1）。
- **子类型与年表**：1764 Walpole《奥特朗托城堡》（再版加副标题「A Gothic Story」），含古堡、家族诅咒、受威胁的女主 → 1790s 安·拉德克利夫《奥多芙堡的神秘》以心理暗示制造悬念、最终给出理性解释；马修·刘易斯直呈暴力与邪恶本体 → 1818《弗兰肯斯坦》（哥特＋科学）→ 1897《德古拉》、1898 亨利·詹姆斯《螺丝在拧紧》（犹疑的典范）→ 20 世纪融入现代恐怖与心理惊悚；哥特元素也被现实主义小说借用（如《简·爱》的阁楼与疯女人）。
- **代表作**：《奥特朗托城堡》《奥多芙堡的神秘》《弗兰肯斯坦》《德古拉》《螺丝在拧紧》、爱伦·坡短篇、《厄舍府的倒塌》。
- **赏析抓手**：恐惧来自外部怪物、空间还是叙述本身；作者在哪一页才让读者确认超自然；建筑（古堡／地牢／阁楼／长廊）如何组织视线与退路；有没有社会批判藏在鬼怪背后。
- **创作要点**：延后揭示，先写「不对劲的日常」；关闭人物的退路比增加血腥更有效；决定好走哪条 Todorov 路线并贯彻到底，别在中间临时用设定补洞。
- **易错**：古堡、雷雨、蜡烛只是道具，不构成哥特；哥特 ≠ 恐怖的全部（恐怖可以是纯心理或纯身体）；把借用了哥特气氛的现实主义作品整部归为哥特小说。

## §5 武侠 / 仙侠 / 玄幻

- **契约**：存在一个有秩序、有师承、可成长的江湖或修行世界，且「侠」（或「道」）在结局处得到价值裁决；读者期待成长、快意与规矩被重新确认或改写。
- **机制**：武功／境界作为可积累的能力体系；门派、辈分、恩怨、江湖规矩构成社会结构；历史框架提供合法性。
- **子类型与年表**（C 级资料，年份待一手复核）：1915 年上海《小说大观》首次以「武侠小说」作分类 → 1923 平江不肖生《江湖奇侠传》为旧派起点，「北派五大家」分出奇幻仙侠（还珠楼主《蜀山剑侠传》）、社会反讽（白羽《十二金钱镖》）、悲剧侠情（王度庐《卧虎藏龙》）、帮会技击（郑证因《鹰爪王》）、奇情推理（朱贞木《七杀碑》） → 1954 年香港吴陈比武热潮催生梁羽生《龙虎斗京华》，新派提出「以侠胜武」，融武侠、历史、言情 → 金庸 1955–1972 共 15 部，有旧版／新版／新修版三个版本系统 → 古龙把推理框架引入武侠 → 网络时代仙侠、修真、玄幻兴起（《飘渺之旅》一类的等级序列常被视为修真数值化的早期范例）。
- **代表作**：《江湖奇侠传》《蜀山剑侠传》《卧虎藏龙》《七剑下天山》《射雕英雄传》《天龙八部》《多情剑客无情剑》《楚留香传奇》。
- **赏析抓手**：这部作品把「侠」定义成什么（为国为民／逍遥／守规矩／报私仇）；武功描写是写实还是写意，是否承担性格；历史大事与虚构人物的接缝在哪；成长是否付出代价。
- **创作要点**：先定江湖秩序与违反它的代价，再定能力边界；招式名服务于人物关系，不堆清单；金庸式「大历史＋个人恩怨」只是一种范式，不是武侠的定义。
- **易错**：武侠 ≠ 奇幻（价值核心是侠与人间秩序，不是第二世界规则）；仙侠／玄幻常与网文升级流叠合，须同时标注生产轴；版本差异会影响文本分析（谈金庸某处描写前先说清所用版本）。

## §6 言情 / 罗曼史 Romance

- **契约**：**中心是恋爱关系，且给出情感满足、乐观的结局**。据 RWA 通行定义的两要素：一段驱动主线的核心爱情 + 一个 emotionally satisfying and optimistic ending；实践上落为 HEA（happily ever after，结局给出长久承诺的证据）或 HFN（happy for now，此刻在一起且向好，未来留白）。这是「读者契约」最清晰、也最不容含糊的例子：读者知道终点，买的是过程。
- **机制**：相遇—靠近—阻力—「黑时刻」（看似不可能在一起）—兑现；阻力多来自人物内心的错误信念与伤口，外部阻碍只是把它逼出来。tropes（enemies to lovers、friends to lovers 等）是可替换的零件，HEA 不是。
- **子类型**：当代、历史（摄政时期等）、浪漫悬疑、超自然／paranormal、romantasy（浪漫奇幻，爱情必须与奇幻主线等重）、甜宠／无露骨描写等；热度量级（spice level）是读者元数据，不是文学等级。
- **中文语境辨析**：中文「言情小说」的外延比英语 `romance` 宽，常包含悲剧、家族伦理与社会言情（才子佳人、张恨水、琼瑶、网络女频），**不一定承诺 HEA**。写比较时必须注明用的是哪一语境，不能用 RWA 标准去否定中文言情里的悲剧经典。
- **赏析抓手**：把爱情线抽掉，故事是否塌掉（能抽掉就只是「有爱情线的小说」）；阻力是否长在人物身上；结尾的「在一起」是否被前面的代价挣得出来。
- **创作要点**：先写两人的伤口与错误信念，再排靠近／退缩节拍；黑时刻必须由这个信念造成；结尾要在页面上给出关系可持续的证据，别靠一句「从此幸福」。
- **易错**：悲剧爱情不是（英语意义上的）romance；悬疑小说加恋爱副线不等于浪漫悬疑；把 HEA 当成套路可以随意打破——它是标签与读者之间的合同。

## §7 历史小说 Historical Novel

- **契约**：在可核验的历史语境里安排虚构人物与事件；作者不暗中改写关键史实，若改写须在文本内外声明。
- **机制**：史实与虚构的边界协商；时代语言、器物、制度与观念构成人物的行动边界（而不是布景）。
- **年表与代表作**：通常以司各特《威弗利》（1814）为现代历史小说起点（通行说法，界定有争议）；中国有历史演义传统（《三国演义》，属章回体，与现代历史小说契约不同），当代如姚雪垠《李自成》、凌力《少年天子》；历史推理（铁伊《时间的女儿》）是推理的旁支。
- **赏析抓手**：列一张「不动清单（年代、人物结局、制度）」与「可动清单（虚构人物、私人生活、对话）」；找作者在哪一处让现代观念借人物之口说话；看大事件如何落到一个人的日常。
- **创作要点**：动笔前写清两份清单；让时代限制先于人物愿望起作用；考据细节只在影响选择时才写。
- **易错**：穿越／架空历史不属于历史小说（属奇幻或网文类型）；「新历史小说」是第 4 轴思潮，不是这里的契约；把「历史背景 + 现代爱情」当历史小说。

## §8 成长小说 Bildungsroman

- **契约**：一个人从少年到成年、经历试炼并与社会达成某种整合（或明确拒绝整合）；读者读的是「变化如何一步步发生」。
- **机制**：失落／不满 → 离家出走 → 与社会的摩擦、导师与反例 → 整合或拒绝；Britannica 指出传统上结局积极、常带克制与怀旧，20 世纪以后则更多以顺从甚至死亡收尾。
- **年表与代表作**：Wieland《阿伽通的故事》（1766–67）或歌德《威廉·迈斯特的学习时代》（1795–96）被认作起点；术语由 Morgenstern 1819 年提出、Dilthey 1870 年确立、1905 年推广。狄更斯《远大前程》、夏洛蒂·勃朗特《简·爱》、《大卫·科波菲尔》、劳伦斯《儿子与情人》、塞林格《麦田里的守望者》、莫里森《最蓝的眼睛》。变体：Künstlerroman（艺术家成长）、Erziehungsroman（教育）、Entwicklungsroman（一般发展）。
- **赏析抓手**：触发出走的具体失落是什么；每一次改变付出了什么；结尾是接受社会规范、重定义它，还是拒绝；谁代表「社会」。
- **创作要点**：把成长拆成若干次有代价的修正，别用一次顿悟完成；给社会一个具体的代言人（家庭、学校、单位、街坊），不要写成抽象的「世俗」。
- **易错**：主角是少年 ≠ 成长小说；成长可以失败或以死亡告终；把「青春文学」「校园题材」直接等同成长小说。

## §9 乡土 / 市井（题材与风格轴，不是类型契约）

- **定位**：主要落在第 2 轴（题材）与第 5 轴（散文化、白描），偶尔被追认为流派或「派」，但**没有统一的读者契约**；这一点必须与前八类分开讲。
- **质地**：地方风物、方言口语、岁时节令、日常伦理、非戏剧化的结构；靠意境、物象与心理变化组织文本。
- **代表作与作者**：鲁迅乡土小说、沈从文《边城》、赵树理《小二黑结婚》、孙犁《荷花淀》、汪曾祺《受戒》、冯骥才《三寸金莲》。
- **赏析抓手**：风物是背景还是结构；方言在什么场合出现、「谁在说给谁听」；没有激烈冲突时，靠什么推进（物象、节气、目光、饭桌）。
- **创作要点**：先掌握那个地方的具体生计与说话方式，再谈意境；不要用抒情旁白替代生活细节。
- **易错**：写农村就自称乡土流派；把「荷花淀派」「山药蛋派」当成有组织、有宣言的文学社团（是否成派有争议）；与 1980 年代「寻根文学」混同——后者是有主张的思潮。

## §10 网络类型（生产与接受轴）

- **定位**：**不是独立的美学类型**，而是「传统契约被连载机制改造后的形态」。同一部作品可以同时是科幻／言情（第 3 轴）与网络类型（生产轴）。讨论时必须同时标两条。
- **契约**：连载中持续兑现「困境—借助外挂解决—变强／得偿」，且不能长时间断档；读者用订阅、月票、评论实时介入，节奏与结构因此被塑造。
- **机制**：金手指（外挂）、数值化成长、章节钩子、副本与关卡、读者反馈驱动的情节调整。中国社会科学网 2023 年文章把穿越、无限流、系统文读成网络社会的生存表征：穿越对应「存档重置」，无限流对应「结构重复」，反派常是无情的「系统」而非具体的人或神。
- **子类型与年表**（据 2025–2026 年资料，标签每年变化）：男频／女频的频道分化；玄幻、都市、职场、种田、职业文、穿越、重生、无限流（得名自《无限恐怖》，21 世纪第二个十年进入大众视野）、「系统流」（约 2014 年起，光明日报 2025-10-11 文章指出它不是封闭类型，而是把「系统」简化为一组规则与数值，混入既有类型的枢纽，如《大医凌然》）；2025 年报告提到跨题材融合、「游戏现实主义」等新提法（如《十日终焉》被作为例子）。2003 年起点中文网 VIP 付费制度、1998 年《第一次的亲密接触》常被称为网文元年，均来自 C 级资料，引用前须复核。
- **赏析抓手**：把「升级」翻译成人物处境的变化，而不只看数值；看单章钩子如何切割因果；看系统／规则是否替代了人物的选择；看读者反馈在文本里留下的痕迹。
- **创作要点**：先定「每次兑现的最小单位」与升级规则；系统只能制造冲突，不能替人物解决价值抉择；规则一经给出就要遵守，否则读者会按契约追责。
- **易错**：把连载节奏、爽点、套路直接判为文学缺陷（那是契约的一部分，评的是兑现质量）；把平台标签当永久分类；引用读者规模、市场规模、榜单名次却不写资料日期。

## 相邻边界速查（最常被问的八组）

| 一组 | 一句话分界 | 判据 |
| --- | --- | --- |
| 科幻／奇幻 | 新事物是「原则上可解释」还是「规则化的魔法」 | 推演 vs 世界规则；人物是否惊讶 |
| 奇幻／魔幻现实主义 | 第二世界、魔法有规则、人物惊讶 vs 本世界、不解释、没人惊讶 | 深判定转 `magic-realism` |
| 奇幻式犹疑／哥特／恐怖 | 犹疑是否一直不解决 | Todorov 三分 |
| 本格／社会派／硬汉派 | 谜与解答为中心 vs 成因与制度为中心 vs 侦探在腐败世界里生存 | 线索公平性、结尾给什么 |
| 悬疑／推理 | 只承诺紧张与未知 vs 承诺公平线索与解答 | 有没有可复核的解答 |
| 武侠／仙侠／玄幻 | 侠与人间秩序 vs 修行与境界 vs 网文升级机制 | 价值核心 + 生产轴 |
| 言情／有爱情线的小说 | 抽掉爱情线，故事是否塌掉；结尾是否 HEA／HFN | 契约 + 中文语境辨析 |
| 历史小说／穿越／新历史 | 史实不动 vs 现代人进入过去 vs 重述历史的思潮 | 第 3 轴与第 4 轴分开 |
