# 通用赏析框架：七维读法、题型模板与误读清单

单篇赏析、答题与文学短评共用的操作手册。SKILL.md 给出五步流程，本文件给出每一步该问什么、怎么落笔。

## 一、七维读法细化

| 维度 | 提问清单 | 到文本里找什么 | 答题落点 |
| --- | --- | --- | --- |
| 人物 | 谁在变？谁在看？谁被环境推着走？谁只负责递消息？ | 肖像、语言、动作、心理、他人评价、称呼变化 | 性格特征 + 变化轨迹 + 典型意义；圆形／扁平人物 |
| 情节 | 线索是什么？哪里延迟、哪里突转？伏笔在哪照应？ | 时间词、反复出现的动作、明暗两条线、结尾回扣 | 概括情节 / 分析线索 / 情节作用 / 情节手法 |
| 环境 | 自然写了什么？社会写了什么？二者怎么叠在一起？ | 天气、器物、机构、职业、物价、众人的议论 | 提供时空、渲染气氛、烘托心理、推动情节、暗示主题 |
| 叙事 | 谁在讲？他知道多少？顺序、节奏、腔调如何？ | 人称、视角越界、倒叙插叙、概述与场景的交替 | 限知视角的空白、儿童／女性视角、嵌套叙事、讲述与显示 |
| 物象 | 什么东西出现三次以上？每次含义变了吗？ | 被反复点名的物件、数字、颜色、气味 | 线索、人物命运的见证、象征、主题载体、推动情节 |
| 语言 | 长句还是短句？白描还是工笔？谁在说方言？ | 动词、叠词、句式、反语、口语、叙述者的评语 | 讽刺、诗化、电报式短句、说书人腔调、冷峻 |
| 主题 | 这些手法合起来让什么变得可见？ | 首尾的对照、标题、作者或叙述者的直接评判 | 批判、人性美、异化、成长、记忆与遗忘、制度与命运 |

「人物—情节—环境」是三要素，「叙事—物象—语言」是三件工具，「主题」是它们的合力。答题时从题干问的那一维切入，但结论要能回到另外两维。

## 二、六步读法（比 SKILL.md 的五步更细）

1. **定位**：册次、单元、课号、教读／自读、节选与否、作者与时代。节选篇目先补一句全篇上下文。
2. **复述**：一句话情节 + 主要人物 + 贯穿物象。此步不写主题、不写手法。
3. **定叙述位置**：人称与视角、叙述顺序、节奏、腔调、叙述者是否可靠。写清「读者此刻比人物多知道什么」。
4. **取证据**：至少三处——一处物象／细节、一处环境、一处人物言行。抄原句或精确描述，标出关键词。
5. **解码**：把每处证据接到「内容—结构—主题」三层，允许一象多义，不编一一对应的密码表。
6. **复查**：过第五节的误读清单；确认没有把节选当全篇、把风格当流派、把叙述者搞错、把套话当结论。

**核心检验**：把这一处手法删掉，文本会失去什么？答不上来，说明它只是被点名的术语，不是真在读文本。

## 三、题型与输出模板

### 1. 作用题（某物、某景、某段、某个人物）

```
【结论】一句话点明它同时做了哪两到三件事，不写「为下文作铺垫」了事。
【内容层】引用或描述该处细节，说明它写出了谁的什么处境／心理。
【结构层】说明它如何串起前后（线索、伏笔照应、节奏转折、首尾呼应），给出另一处文本位置。
【主题层】说明它让哪一层意思变得可见；若含反讽或象征，点出反差在哪。
```
例：分析《林教头》的风雪，不能只写「渲染气氛」；要写「雪压塌草厅，林冲才去山神庙，才听见门外密谋」——环境直接改写了情节。

### 2. 含义题（标题、句子、词语）

```
表层义（字面指什么）→ 语境义（在这一段、这个人物嘴里指什么）→ 主旨义（与全篇的反讽、象征或主题如何相连）
```
例：「祝福」表面是鲁镇年末祭祀，落到文本里是祥林嫂死在祝福声中的反讽，再落到「谁有资格被祝福」的制度性追问。

### 3. 形象题

```
先给身份与处境 → 分点给性格，每点挂一处言行或他人反应 → 补变化轨迹 → 给典型意义（这个人物替哪一群人说话）
```
圆形人物写「矛盾与变化」，扁平人物写「被放大的一个特征及其作用」，不拿一把尺子量所有人物。

### 4. 叙事视角题

```
叙述者是谁（年龄、身份、与事件的关系）→ 他能知道什么、不可能知道什么 → 这种信息差给读者带来什么（真实感／空白／反讽／悬念）→ 服务了什么主题
```
例：《大卫·科波菲尔》的童年视角，让债务、童工这些成人世界的荒诞以孩子不懂的口吻说出来；《祝福》的「我」被祥林嫂追问灵魂，把知识分子也写进了被审判的位置。

### 5. 比较题

```
共同机制（两篇都用了什么）→ 逐项差异（至少三项，各带证据）→ 差异的成因（时代、文体、文化、流派）→ 各自不可替代的价值 → 不作优劣裁定
```
禁止写成两段互不相干的内容简介。对照专题见 `references/literary/textbook-fiction/comparisons.md`。

### 6. 文学短评

```
开头给出一个可争辩的中心判断（不是「本文语言优美」）。
主体两到三段，每段一个分论点 + 一处细读证据 + 一句推进。
结尾回到中心判断并留一点余地，不喊口号、不升华成时代赞歌。
```

### 7. 赏析题答案（应试）

- 分点作答，每点一句结论 + 一句文本依据；术语只在能帮上忙时用。
- 6 分题通常三到四个得分点，但点数不等于字数，写满三行空话不如两处准确引用。
- 不写「参考答案式」的万能句：「深化了主题」「引起读者兴趣」后面必须跟「怎么深化」「对什么产生兴趣」。

## 四、术语表（首次出现时给一句白话解释）

| 术语 | 白话解释 | 典型篇目 |
| --- | --- | --- |
| 限知视角 | 只写叙述者此刻能知道的事，留下空白 | 百合花、祝福、党费 |
| 全知视角 | 叙述者知道多方动向，可写人物不自知的事 | 林教头、促织、荷花淀 |
| 内聚焦 | 叙述始终贴住一个人物的意识 | 变形记 |
| 嵌套叙事 | 故事里有人再讲一个故事，形成层次 | 装在套子里的人、祝福 |
| 预叙 | 提前说出将来会发生的事 | 百年孤独 |
| 讲述 / 显示 | 叙述者出面评议 / 让场景自己呈现 | 促织 / 变形记 |
| 扁平人物 | 被放大一个特征、基本不变的人物 | 米考伯先生 |
| 圆形人物 | 有内在矛盾、会变化的人物 | 聂赫留朵夫、林冲 |
| 心灵辩证法 | 写出心理运动的全过程与自我辩驳，不只写结论 | 复活 |
| 冰山原则 | 只写八分之一，余味藏在水下，靠简洁与留白 | 老人与海 |
| 白描 | 不加铺陈，用简笔勾勒动作与神态 | 鲁迅、赵树理、施耐庵 |
| 散文化／诗化小说 | 淡化情节冲突，以意境、物象与心理变化组织 | 百合花、哦香雪、荷花淀、边城 |
| 典型环境 | 具体的时代、制度与人群关系，不只是布景 | 祝福、林教头、促织 |
| 异化 | 人被工作、金钱或制度抽走价值，变成「非人」 | 变形记、促织（广义） |
| 荒诞与真实 | 设定不可能，细节与反应却极度可信 | 变形记、促织 |
| 以喜写悲 | 用喜剧或团圆的表面反衬深层悲剧 | 促织 |
| 反讽 | 字面与实情相反，或标题与结局相撞 | 祝福、阿Q正传、套中人 |
| 物象 | 反复出现、承担结构与象征的具体物件 | 百合花被子、铅笔盒、咸菜 |
| 潜台词 | 对白里没说出口的顾虑与关系 | 荷花淀 |
| 山药蛋派 / 荷花淀派 | 有地缘与师承的作家群体，可称流派 | 小二黑结婚 / 荷花淀 |

「扁平／圆形人物」来自 E. M. 福斯特《小说面面观》，是教学常用概念，不是教材给人物定的等级。

## 五、常见误读清单

1. **把风格当流派**：诗化、散文化、讽刺是文本风格；荷花淀派、山药蛋派、魔幻现实主义才是有谱系的流派。教材 16 篇里能挂流派标签的只是少数。
2. **把《促织》叫魔幻现实主义**：文言志怪与浪漫主义幻想，有明确因果、有「异史氏曰」的作者评判；与拉美魔幻现实主义的现实基底、不解释、不动声色不同。
3. **把《变形记》叫魔幻现实主义**：现代主义的荒诞与异化，人物与读者都受冲击；魔幻现实主义里只有读者觉得奇怪。
4. **把《装在套子里的人》的讲述者搞错**：布尔金讲故事，伊凡·伊凡内奇听故事；课文是节选，外层框架不完整。
5. **把《阿Q正传》的「我」当全程叙述人称**：作传人的「我」时出时没，主体是全知叙述加议论。
6. **把节选当全篇**：谈框架、结局、人物完整弧线前，先确认课文边界。
7. **把「我」等同作者本人**：《祝福》《百合花》《党费》《大卫·科波菲尔》里的「我」都是文本里的角色。
8. **把「反映了……」当分析**：这类句子是结论的开头，不是结论本身。
9. **把环境只当背景**：风雪、祝福的雪、荷花淀的荷叶都改写了情节。
10. **把象征做成密码表**：铅笔盒、白塔、鱼骨架允许多义，不写「某某一定等于某某」。
11. **把喜剧结局读成团圆**：《促织》的封赏恰恰放大了悲剧。
12. **把单元人文主题当教材原文**：是教师用书与教研的通行概括，措辞不唯一。
13. **编造高考真题卷别与年份**：不确定时写「常见考法」，不写「某年某卷」。
14. **用「想象奇特瑰丽」「歌颂人性美」结案**：须指出是哪处叙述、哪件物、哪句对白让判断成立。

## 六、赏析质量自检

- 有没有写出册次、课号与是否节选。
- 有没有指认叙述者及其信息范围。
- 有没有至少三处具体文本证据，其中至少一处是原句或精确细节。
- 每个「作用」是否落到了内容、结构、主题中的至少两层。
- 有没有一处「删掉它会失去什么」的检验。
- 有没有把时代与制度写具体，而不是只写「黑暗的旧社会」。
- 有没有避开第七节的空话与密码表式解读。
- 比较题有没有写出共同机制与至少三项差异，而不是两段简介。

## 七、资料层级提醒

篇目、课号、自读标记以官方教材目录为准；单元人文主题、风格归属、题型归纳来自教研与教师用书；教学公众号的具体判断（尤其流派标签、真题年份）只作线索，需复核后使用。来源清单见 `references/literary/textbook-fiction/texts.md`。
