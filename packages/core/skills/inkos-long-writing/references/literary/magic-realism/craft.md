# 创作方法论：把不可能写进可核验的现实

SKILL.md 给出创作七步与六项体检；本文件是细化手册，供真正动笔、改稿与做练习时读取。

## 一、先立「真」，再定意象

顺序不可颠倒。先在内部写下一句不带文学腔的话，作为全篇的地基：

> 这一段要写的是：某年某地的某群人，有一件人人知道、没人记账的事。

「真」的几种类型：被官方或家族否认的死亡；一笔没人认的欠账；一场集体沉默的事故；一种说不出口的思念；一个人被从名册上抹掉；迁徙后回不去的原址。写自己知道的地方与年代，不写没查过的异域。

由「真」推意象，五条常用路径：

| 路径 | 做法 | 示范（仅示范推导，不直接取用） |
| --- | --- | --- |
| 隐喻字面化 | 把一句日常说法当成事实写 | 「这笔账没完」→ 欠条每月自己长一截 |
| 信仰字面化 | 把当地人真会信、真会怕的观念照实写 | 老人说亡者逢饭点回来 → 饭点真的多一副碗筷、多一个湿脚印 |
| 官方谎言字面化 | 让被否认的事以物理方式留下痕迹 | 「没死人」→ 井里每天浮上一张当年的票据 |
| 尺度失真 | 用精确数字把夸张写成账目 | 不说「下了很多纸」，说「数到第九张就不数了」 |
| 时空失序 | 让过去占用现在的空间 | 拆掉的水泥厂每逢夜班又亮灯，机器声照旧 |

一个短篇只用一个主意象。长篇可以有一个主意象与两三处回响，但每一处都要能回答「它替哪件事作证」。

## 二、开工单（内部填写，不交给用户）

1. 那一句「真」，写到具体年份、地点、人群。
2. 现实基底十项：地名、年份、季节、主要生计、机构名称、钱与票证、作息、天气、气味、一句当地人真会说的话。
3. 唯一的主意象，以及它违反的物理常识与服从的情感逻辑。
4. 见证者：谁第一个看见，谁不信，谁负责善后。
5. 人物的务实反应清单：报不报、怎么收、谁付钱、邻居怎么说。
6. 视角位置：跟谁的眼睛走，他此刻不可能知道什么。
7. 时间形状：线性、循环、回望，还是长雨式停滞。
8. 结尾留在哪一个具体物件上（不揭晓机制）。

## 三、现实基底怎么才算写足

魔幻的可信度来自现实的密度，不来自解释。以下每类至少落三处具体名词：

- **物质**：粮票、工分本、水泥袋、锄头、搪瓷缸、社保卡、快递面单、井台、竹竿。
- **制度**：大队、厂里、户籍、班组、粮站、村小、值班表、报销单。
- **计量**：斤、尺、块、第几张、第几夜、几点几分。精确数字比形容词可信。
- **身体**：冻裂的手、井绳磨出的茧、米饭里的沙、汗味、薄冰。
- **语言**：称呼、口头禅、骂人的分寸、谁有权给谁派活。

大致九成篇幅严格写实。现实写薄了，越界就只是段子。

## 四、语气：全篇最关键的技术

叙述奇迹与叙述「番茄酱用完了」使用同一套句法、同一温度。马尔克斯的说法是自己先相信，再用外祖母的方式不动声色地讲出来；外祖母讲令人毛骨悚然的故事时，面部表情毫无变化。另一条经验是精确数字：说三头大象在飞没人信，说四百二十五头反而有人信。

**反例（不要这样写）**

> 那天清晨，全村人惊恐地发现，井里竟浮起了三十年前沉下去的粮票！谁也说不清这是怎么回事，仿佛有一股神秘的力量在作祟，要把那段被遗忘的岁月重新翻出来。

问题：惊叹、解释欲、抽象主题句、「仿佛」式抒情、人物集体惊讶。四层契约一次破完。

**正例（同一材料）**

> 腊月十七，井台结了薄冰。队长家的媳妇打水，桶里带上来一张一九六一年的粮票，纸还挺，字没糊。她把粮票摊在井沿上晾，回家换了只小桶，第二天照旧来打水。后来井里每天上来一张，队里派人守了三夜，数到第九张就不数了，说年前事多。

可拆解的做法：日期与节气 → 具体动作 → 物件的物理状态（挺、没糊）→ 务实处置（摊开晾、换小桶）→ 频率与精确数字 → 一句带社会逻辑的收束（年前事多）。没有一句解释原理，没有一句抒情，「那段被遗忘的岁月」由物件自己承担。

**语气硬禁令**：竟然、居然、竟、居然、奇迹般地、令人难以置信、不可思议、诡异、神秘的力量、原来是因为、仿佛要把……、命运般地；叙述层感叹号；「怪事发生了」一类旁白提示。

## 五、人物怎么反应

- 不争论真假，只争论后果：报不报、谁去说、要不要换口井、纸能不能晒干、队里记不记账。
- 允许不同人物有不同解释，但叙述者不裁决。
- 权威人物的反应要符合其利益：队长怕影响年终，会计怕账对不上，老人只问是不是那一年的。
- 「守了三夜，数到第九张就不数了」这类放弃追问，比追查到底更接近这一模式：现实的压力大过好奇心。

魔幻不用于解决情节。禁止用它复仇、破案、复活关键人物、在结尾翻盘；它只加深处境。

## 六、时间与结构手法

| 手法 | 怎么用 | 风险 |
| --- | --- | --- |
| 回望式开篇 | 从多年后的一个场景回看某个下午，一句里叠未来、过去、现在 | 只借结构，不仿写任何经典原句 |
| 循环时间 | 重复的姓名、节气、动作与句式，含义每次变化 | 纯形式重复会变成炫技 |
| 停滞 | 长雨、长旱、长夜，让历史暂停在一个画面 | 要有生活细节撑住，不能只写天气 |
| 压缩 | 几十年用一段概述带过，关键一天用数页慢写 | 概述里别塞主题判断 |
| 多版本口述 | 同一件事三个人三种说法，并列放置 | 不揭晓谁对 |
| 开放式收束 | 停在物件、账目或一次日常动作上 | 不写「原来这一切都是……」、不升华、不首尾呼应打卡 |

短篇：一个魔幻点、一次务实处置、一个不解释的收束。长篇：跨章保持现实台账（人物、年份、已发生的不可逆事件、意象出现次数与含义变化），不为救场临时加新规则。

## 七、中文写作的在地性与边界

- 不搬运玛雅神话、吉普赛人、香蕉公司、黄色蝴蝶、马孔多、羊皮卷、飞毯、升天等符号；这些属于别人的现实，不是气氛素材。
- 用本地人真会信、真会怕的东西：族谱、坟山、井、祠堂、值班表、旧账、口信、忌日、称呼禁忌。
- 借民间信仰时写出它的社会位置：谁信、谁不信、谁靠它管人，不写成供参观的民俗表演。
- 写创伤、贫困、暴力时让镜头留在承受者身上，取消旁观者的赏玩视角。
- 与中文「活人感写作」一致的部分：动作托情绪、段落必须推进、不写「他感到孤独」「命运压了下来」、结尾不升华不摘要。允许对白前导冒号与被打断的台词。
- 用户明确要求模仿某位在世作家的调性时，只取可复述的手法特征，不仿写原句、不复制专有设定。

## 八、改稿顺序

按此顺序改，不要一上来润色句子。

1. **删机制**：任何解释来源、规则、代价、血统、训练、原理的句子，整段删。
2. **删惊叹**：替换语气硬禁词，删掉人物「不敢相信」的反应，改写成处置动作。
3. **补现实**：在魔幻出现前后各补两处可核验的物质、制度与计量细节。
4. **过移除测试**：把主意象整段删掉读一遍。若主题毫发无损，说明选错了意象，回到第一节重推。
5. **过在地测试**：圈出所有异域符号与民俗猎奇，换成当地人真的在乎的东西。
6. **删主题句**：删掉「那段被遗忘的岁月」「命运终于」一类替读者总结的话，停在具体物件上。

长稿保存后可运行 `python scripts/check_magic_realism.py <稿件路径>` 做形状体检。脚本只标出可疑词与感叹号密度，命中不等于违规，最终由人工按六项体检判断。

## 九、交稿前清单

- 现实基底能否指出具体年份、地点、机构与钱物。
- 主意象是否只有一个，且不可化约、未被解释。
- 叙述者与人物是否都没有惊讶。
- 是否有至少一处精确数字与一处物理细节。
- 人物是否在处理后果而非争论真伪。
- 删掉魔幻后，故事是否真的缺了一块。
- 结尾是否留白、不揭晓机制、不升华。
- 全文有没有「魔幻」「命运」「宿命」「时代」「这片土地」等自我标签。

## 十、练习（用于打磨手感）

1. 写一个房间里每晚长高一厘米的故事，全家唯一在意的是门还能不能关上。不许出现任何解释。
2. 把一句俗语（「欠债还钱」「纸包不住火」）字面化，放进一个有真实年份与机构的中国场景。
3. 同一个事件写三个版本：当事人的、邻居的、台账上的，三版并列，不裁决。
4. 把一段自己写过的抒情段落改写成井台、账本与动作，不许出现情绪词。
5. 改写练习：给一段满是惊叹与解释的「奇观」文字，只保留事实与处置动作，删到原来一半篇幅。

## 十一、与其它 Skill 的边界

- 需要都市奇幻、隐藏世界、异能代价体系与青春长篇结构时，改用别的类型 Skill；本 Skill 明确反对魔法体系。
- 需要非虚构长文、知乎回答、行业解读时，用通用中文写作 Skill；本 Skill 只处理小说与小说赏析。
- 用户既要赏析又要创作时，用 `references/literary/magic-realism/analysis-framework.md` 拆出的手法做创作输入，但不把赏析笔记写进作品正文。
